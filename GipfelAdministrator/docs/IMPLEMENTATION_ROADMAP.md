# Implementation roadmap

- Phase 0 — reproducible monorepo, emulator safety, architecture and security decisions.
- Phase 1 — alpine design system, responsive application shell and accessible primitives.
- Phase 2 — authentication boundary, tenant context, RBAC and scoped repositories.
- Phase 3/3B — reservation state machine, availability, guests and connected admin UI.
- Phase 4 — server-owned payments, refunds and invoices.
- Phase 5 — mock communication and operational tasks.
- Phase 6 — deterministic integer-cent rate engine.
- Phase 7 — allowlisted multilingual static website export.
- Phase 8 — onboarding, platform administration and subscription model.
- Phase 9 — inactive provider architecture and planned Smoobu adapter.
- Phase 10 — emulator, browser, responsive, accessibility and security acceptance gate.

No phase authorizes deployment, migration, live mail, payment transactions or a channel-manager connection.
